# resume-links

Static link hub for Paul Quemin's resume QR code.

## Publish to GitHub Pages

1. Create a **public** repository named `resume-links` on GitHub.
2. Push this folder's contents to the `main` branch (root).
3. Go to **Settings > Pages**.
4. Under **Source**, select **Deploy from a branch**.
5. Set **Branch** to `main` / `/ (root)`.
6. Save. The site will be live at:
   `https://poppolopoppo.github.io/resume-links/`

No build step required. GitHub Pages serves the files as-is.
